# 讀書小夥伴（Ameba Study Buddy）

課程作業「讓 Ameba 看懂生活——影像辨識創意實作」的第一週成果。

AMB82-MINI 的攝影機固定在書桌前，在開發板上用 YOLOv7-tiny 判斷使用者是否在桌前，記錄在桌前的時間、離席次數和每次離開多久。網頁上的像素小雞會跟著狀態變化，不跳通知、不發聲。

## 功能

- **在座計時**：人連續出現 3 秒算「在桌前」，開始累計時間。
- **離席紀錄**：超過 10 秒沒看到人，記一次離席；回座後算出離開多久。
- **自動分類活動**：
  - 書本持續出現 → 讀書中；
  - 筆電，或鍵盤＋滑鼠持續出現 → 用電腦中；
  - 兩種都有或都沒有 → 在桌前。
- **手機提示**：手機出現時只提示，不影響計時。
- **容錯**：偵測短暫中斷或推論逾時時，顯示「無法確認」並暫停累計，不算離席。

所有辨識都在開發板上執行，網頁只負責顯示。

## 狀態

| 狀態 | 條件 | 計時 |
|---|---|---|
| `PRESENT` 在桌前 | 人持續 3 秒，沒有書也沒有電腦線索（或兩者同時出現） | 桌前時間 |
| `STUDYING` 讀書中 | 人持續 3 秒，而且只有書本持續出現 | 桌前時間＋讀書時間 |
| `COMPUTER` 用電腦中 | 人持續 3 秒，而且只有筆電或鍵盤＋滑鼠持續出現 | 桌前時間＋電腦時間 |
| `UNSURE` 無法確認 | 人剛出現或剛消失、物件推論逾時 | 暫停 |
| `AWAY` 未偵測到使用者 | 超過 10 秒沒看到人 | 暫停，離席次數 +1 |

## 檔案

```
Day3_StudyBuddy_Verify/
  Day3_StudyBuddy_Verify.ino   主程式：影像、推論、狀態機、序列埠輸出、RTSP
  DetectionEvidence.h          最近 5 秒的命中統計，用來判斷物品是否「持續出現」
  SceneRelations.h             書／手機與人、桌子的位置關聯，以及鍵盤＋滑鼠的電腦線索
web/
  pet_test.html                像素小雞網頁，透過 Web Serial 讀取開發板的 STATE 輸出
```

## 需要的東西

- Ameba AMB82-MINI 開發板與攝影機（預設 JXF37）
- USB 線、電腦
- Arduino IDE，加上 Realtek AmebaPro2 開發板套件
- 2.4 GHz Wi-Fi（只有用 VLC 看辨識畫面時需要）
- Chrome 或 Edge（網頁要用 Web Serial）

## 使用方式

### 1. 燒錄韌體

1. 用 Arduino IDE 開啟 `Day3_StudyBuddy_Verify/Day3_StudyBuddy_Verify.ino`。
2. 把 `ssid`、`pass` 改成自己的 Wi-Fi。
3. 開發板選 **AMB82-MINI**。
4. 讓開發板進入燒錄模式：按住 BOOT，按一下 RST，再放開 BOOT。
5. 上傳程式。完成後按一下 RST，程式開始執行。

### 2. 看辨識畫面（選用）

序列埠會印出 `rtsp://<板子 IP>:554`。用 VLC 開啟這個網址，就能看到偵測框和左上角的狀態。

### 3. 開網頁

1. 用 Chrome 或 Edge 開啟 `web/pet_test.html`。
2. 按「連接開發板」，選擇開發板的 COM 埠（115200 baud）。

網頁會佔用 COM 埠。要重新燒錄前，請先關掉網頁或中斷連線。

### 4. 擺放建議

- **鏡頭**：放在使用者正前方，約眼睛高度，距離 60～80 cm，向下俯約 30°。
- **入鏡範圍**：肩膀、上半身和桌面都要在畫面內。
- **書和手機**：書斜立在閱讀架上，手機放支架上，比較容易被偵測到。

## 序列埠輸出

每秒輸出兩行，開機時會先印出欄位名稱：

- `CSV,...`：各類物件每秒的命中次數與最高分數，用來校正門檻。
- `STATE,t_s,state,desk_s,study_s,computer_s,mode,away_count,last_away_s,...`：給網頁讀取的目前狀態與累計時間。

## 可調參數

參數都在 `.ino` 開頭：

| 參數 | 預設 | 說明 |
|---|---|---|
| `NN_CONF_THRESH` | 0.25 | 模型信心門檻。函式庫預設 0.5，會把書和手機的低分結果直接丟掉 |
| `HOLD_MS` | 3000 | 人要持續多久才算在桌前 |
| `AWAY_MS` | 10000 | 多久沒看到人算離席 |
| `GAP_TOLERANCE_MS` | 1500 | 允許短暫漏判的時間 |
| `BOOK/PHONE/LAPTOP_MIN_PERCENT` | 15 / 25 / 40 | 最近 5 秒內要出現多少比例才算持續出現 |
| `USE_RGB_LED` | 0 | 有接 RGB LED 時改成 1 |

## 限制

- 只判斷「人在不在桌前」和桌上物品是否持續出現，不判斷專注、是否真的在讀書，或是否在滑手機。
- `person` 最穩定。`book` 和 `cell phone` 調整後有改善，但仍比較難偵測。
- 只適用單人、固定書桌、光線充足的環境。

## 來源

以 Realtek Ameba Arduino SDK 的 `ObjectDetectionLoop` 與 `ObjectDetectionCallback` 範例為基礎修改，模型為官方提供的 YOLOv7-tiny（COCO 80 類）。
