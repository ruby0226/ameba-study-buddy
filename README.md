# 啾啾的小屋｜Ameba 讀書小夥伴

第二週「讓 Ameba 看懂生活」原型。AMB82-MINI 用攝影機辨識桌前活動，再透過 Wi-Fi 網頁陪伴學習、提醒休息與照顧像素小雞。

## 主要功能

| 辨識情境 | 網頁與獎勵 |
| --- | --- |
| 讀書 | 綠色讀書場景，小雞翻書，累積穀穀 |
| 使用電腦 | 藍色電腦場景，小雞打字，累積穀穀 |
| 手機出現 | 橘色暫停提示，獎勵倒數暫停並保留進度 |
| 離席休息 | 小雞休息，完成休息後恢復活力 |

- Ameba 負責辨識、活動判斷、計時、獎勵和餵食驗證；網頁負責畫面與叫聲。
- 穀穀可以餵小雞，搭配走動、互動動畫與成長。
- 休息時間到提醒一次，繼續久坐再提醒一次；沒有拍手互動。
- 物件偵測到就開始追蹤並給 ID：分數 ≥50 立刻追，其餘 2 秒內再看到一次即追；之後放寬分數、離開桌面區也繼續追，漏看超過 3 秒或從畫面左右上緣拿出 1 秒才算消失。追蹤仍靠每幀 YOLO 的框；書本常被 YOLO 漏判，仍待改善。

手機優先於書本，書本優先於電腦。手機放在桌上也可能觸發，尚不能確認是否正在操作手機；暫停獎勵時，久坐與休息提醒仍繼續。

## 如何使用

1. Arduino IDE 安裝 AmebaPro2 套件，選擇 **AMB82-MINI**。驗證版本為 `4.1.1-build20260922`。
2. 將 `Day3_StudyBuddy_Verify/WiFiSecrets.example.h` 複製為同資料夾的 `WiFiSecrets.h`，填入自己的 Wi-Fi。
3. 開啟 `Day3_StudyBuddy_Verify/Day3_StudyBuddy_Verify.ino`，編譯並燒錄；完成後按一下 **RST**。
4. 序列埠監控設為 **115200**，找到 `Pet web: http://<IP>/`。
5. 電腦或手機連到同一網路，開啟該網址，按「開始陪伴」。

網頁由板子直接提供，日常可用充電器供電。固定鏡頭，讓人物與桌面入鏡；展示單一情境時，把其他物件移出畫面。

## 一般版與展示版

原始碼預設 `PET_DEMO=0`；錄影時改為 `1` 後重新編譯燒錄。

| 設定 | 一般版 | 展示版 |
| --- | --- | --- |
| 第一次休息提醒 | 25 分鐘 | 60 秒 |
| 繼續久坐再提醒 | 約 30 分鐘 | 約 75 秒 |
| 有效休息 | 確認離席後 5 分鐘 | 確認離席後 10 秒 |
| 獲得 1 份穀穀 | 學習累積 5 分鐘 | 學習累積 15 秒 |

網頁須保持連線；斷線或辨識資料過期會暫停養成。資料暫存在 RAM，板子重開機會重設。真實辨識準確率與完整操作影片仍待補測、錄製。

## 修改與文件
